# Green X V4.2 — Mobile & Estimator Polish

## Changes

- Removed the homepage `BUILT FOR` ribbon under the hero estimator.
- Reworked homepage estimator into a lightweight system selector only.
- `Continue to Estimate` opens `/estimate-system-size` and preserves the selected system.
- The dedicated estimator page starts at the requirements step when launched from Home and always provides a Back action.
- Updated all estimator CTAs to use the dedicated estimator route instead of the old homepage anchor.
- Replaced the custom WhatsApp drawing with the recognizable WhatsApp brand silhouette and `#25D366` treatment.
- Added mobile overflow safeguards to prevent half-width / clipped layouts in mobile in-app browsers.
- Reduced mobile header/logo dimensions and improved hero sizing at 920px, 640px and 390px breakpoints.
- Improved mobile hero metrics, cards, estimator controls and fixed bottom action bar.
- Kept the desktop hero selection experience while avoiding a full multi-step form on the homepage.

## Deployment

No database migration is required.

Existing Vercel environment variables remain unchanged:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
- `CLOUDINARY_URL`
